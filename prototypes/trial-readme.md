# 체험판 (프로토타입)

`trial.html` 파일 하나로 열리는 모형입니다. 브라우저에서 파일을 열면 바로 눌러 볼 수 있어요.

## 무엇을 볼 수 있나

- 방문자: 글 읽기, 검색·정렬, 조회수, 공유하기, Google 로그인(샘플 계정), 댓글·답글·@ 호출
- 관리자: 로그인, 글쓰기(서식 도구, 썸네일), 글 관리, 메뉴 관리

## 꼭 알아 둘 점

- 실제 로그인이 아니에요. 관리자 로그인은 이메일과 비밀번호에 아무 값이나 넣으면 되고, Google 로그인은 샘플 계정 3개 중에서 골라요.
- 쓴 글과 댓글은 저장되지 않아요. 새로고침하면 샘플 상태로 돌아가요. 조회수만 이 브라우저에 남아요.
- 실제 블로그에서는 파이어베이스 연결 뒤에 로그인, 저장, 조회수, 이미지 올리기가 동작해야 해요.
- 화면과 동작을 정하는 참고용이에요. 실제 블로그 코드(`build.js`, `assets/`)와는 따로예요.
