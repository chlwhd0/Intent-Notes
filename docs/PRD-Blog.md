## 1. 개요

**이 문서는 무엇을, 어디까지 정하는가**

> "공개 포트폴리오와 **비공개 회고**를 한 곳에서 안전하게 운영하고, 공개 글에는 **대화**를 붙인다."

| 현재 상태 | 이 문서의 범위 | 범위 밖 |
|---|---|---|
| 디자인 시안 2 확정<br>정적 블로그 첫 버전 (GitHub 공개 저장소)<br>체험판: 로그인·글쓰기·댓글·관리자·조회수·공유·썸네일<br>실제 로그인과 저장은 아직 없음 | 방문자: 읽기, 조회수, 공유, Google 로그인, 댓글<br>관리자: 로그인, 글쓰기·썸네일, 글·메뉴 관리<br>화면, 권한, 데이터, 보안 기준, 구현 순서 | 이메일 구독, 뉴스레터<br>광고·수익화<br>다국어, 모바일 앱<br>본문 이미지 넣기는 후보 기능 |

## 2. 문제 정의

**기록은 있는데, 한 곳에 안전하게 모이지 않는다**

기획 가설입니다. 방문자 인터뷰로 검증이 필요해요.

| 문제 | 내용 |
|---|---|
| **문제 1. 흩어진 기록** | 포트폴리오, 회고, 스터디 노트가 여러 곳에 흩어져, 한 사람의 사고 흐름이 보이지 않는다. |
| **문제 2. 공개와 비공개의 경계** | 솔직한 회고를 쓰고 싶지만, 실수로 공개될 위험 때문에 쓰기를 망설인다. |
| **문제 3. 일방향 기록** | 읽는 사람의 질문과 피드백이 글에 연결되지 않고, 소통이 다른 채널로 흩어진다. |

**기회:** 한 블로그 안에서 **공개 글**은 포트폴리오로 보여 주고, **회고**는 관리자만 보게 잠그며, 공개 글 아래에서 **방문자와 대화**한다. 디자인은 직접 통제한다.

## 3. 목표와 비목표

**무엇이 되면 성공이고, 무엇은 하지 않는가**

| 목표 | 측정 방법 (제안) |
|---|---|
| **G1** 첫 방문자가 10초 안에 "누구이고 무슨 일을 하는지" 이해한다 | 첫 화면 소개·최근 글 노출, 5명 사용성 확인 |
| **G2** 회고는 어떤 경로로도 공개되지 않는다 | 비로그인·방문자 계정으로 노출 0건 점검 |
| **G3** 공개 글에서 방문자와 소통한다 | 글당 댓글 수 (목표값 직접 설정) |
| **G4** 글 발행이 가볍다 | 글쓰기 시작부터 발행까지 5분 이내 |

**비목표 (이번 범위 밖)**

- 이메일 구독·알림 발송
- 광고, 유료 구독
- 다국어 지원
- 방문자 간 쪽지, 팔로우
- 이메일·비밀번호 회원가입

## 4. 사용자

**두 부류의 사용자**

| | 방문자 | 관리자 |
|---|---|---|
| 누구인가 | 채용 담당자 · 동료 PM | 블로그 주인 (AI PM) |
| 상황 | 이 사람의 사고 방식과 결과물을 짧은 시간에 파악하고 싶다. | 프로젝트가 끝날 때마다 포트폴리오와 회고를 남기고 싶다. |
| 원하는 것 | 포트폴리오를 카테고리별로 훑고, 궁금한 점은 글에 바로 묻는다. | 글을 빠르게 쓰고, 공개 범위를 실수 없이 정하며, 메뉴와 댓글을 직접 관리한다. |
| 불안 | 로그인을 강요받거나, 모바일에서 읽기 불편한 것. | 회고가 실수로 공개되는 것, 이상한 댓글이 달리는 것. |
| 핵심 원칙 | **읽는 데 로그인은 필요 없다.** 댓글을 쓸 때만 Google로 로그인한다. | **회고는 나만 보고 나만 쓴다.** 관리 권한은 한 계정만 갖는다. |

## 5. 유저스토리

### 방문자 스토리 V1~V13

| ID | 스토리 | 완료 기준 |
|---|---|---|
| V1 | 첫 화면에서 이 사람이 누구인지 알고 싶다 | 이름, 한 줄 소개, 최근 글이 첫 화면에 보인다 |
| V2 | 포트폴리오를 카테고리별로 훑고 싶다 | 메뉴를 누르면 해당 글만 최신순으로 나온다 |
| V3 | 제목으로 검색하고 정렬하고 싶다 | 검색어 입력 즉시 걸러지고, 결과 없으면 안내가 나온다 |
| V4 | 글을 읽고 이전·다음 글로 이어 보고 싶다 | 글 아래에 이전 글, 다음 글 링크가 있다 |
| V5 | 휴대폰에서도 불편 없이 읽고 싶다 | 좁은 화면에서 가로 스크롤이 없다 |
| V6 | 비공개 글이 있다는 사실도 알 수 없어야 한다 | 로그인 전 메뉴·목록·주소 접근 모두 "찾을 수 없어요" |
| V7 | 로그인 없이 읽고, 댓글 쓸 때만 로그인하고 싶다 | 읽기는 로그인 불필요, 댓글 칸에 Google 로그인 버튼 |
| V8 | 댓글을 쓰고 내 댓글을 고치거나 지우고 싶다 | 내 댓글에만 수정·삭제 버튼, 날짜·시간 표시 |
| V9 | 다른 사람의 댓글에 답글을 달고 싶다 | 답글이 원래 댓글 아래에 묶여 보인다 |
| V10 | @로 사람을 부르고, 나를 부른 댓글을 알고 싶다 | @ 입력 시 목록, 강조 표시, 사이드바 "@ 알림" 개수 |
| V11 | 어떤 글을 많이 읽었는지 알고 싶다 | 공개 글 목록·상세에 조회수, 열 때마다 증가, 회고는 없음 |
| V12 | 마음에 드는 글을 공유하고 싶다 | 공개 글에 공유하기(링크 복사, X·Facebook·LinkedIn) |
| V13 | 썸네일로 글을 한눈에 구분하고 싶다 | 모든 글에 썸네일이 보인다 |

### 관리자 스토리 A1~A10

| ID | 스토리 | 완료 기준 |
|---|---|---|
| A1 | 이메일과 비밀번호로 로그인하고 싶다 | 성공하면 관리자 메뉴와 회고가 보이고, 실패하면 이유가 나온다 |
| A2 | 글을 쓰고 공개 범위를 정하고 싶다 | 제목·카테고리·요약·본문(미리보기 포함), 공개/나만 보기 선택 |
| A3 | 회고가 실수로 공개되지 않게 하고 싶다 | 회고를 고르면 공개 선택이 사라지고 "나만 보기(고정)"만 남는다 |
| A4 | 글을 고치고, 공개 전환하고, 삭제하고 싶다 | 글 관리 목록에서 처리, 삭제는 한 번 더 확인 |
| A5 | 메뉴 이름·개수·순서를 정하고 싶다 | 추가·이름 변경·순서 변경·삭제, 모든 화면에 같은 이름 |
| A6 | 글이 남은 메뉴를 실수로 지우지 않고 싶다 | 글이 있는 메뉴는 삭제가 막고 이유가 안내된다 |
| A7 | 로그아웃하면 관리 기능이 바로 막히길 원한다 | 관리자 주소로 들어가면 로그인 화면으로 간다 |
| A8 | 부적절한 댓글을 지우고 싶다 | 모든 댓글 삭제 가능, 다른 사람의 댓글 수정은 불가 |
| A9 | 글마다 썸네일을 정하고 싶다 | 기본 모양 6개 중 선택 또는 이미지 올리기, 허용하지 않는 파일은 거부 |
| A10 | 글이 얼마나 읽혔는지 보고 싶다 | 글 관리 목록에 조회수 열, 회고는 "-" |

## 6. 정보 구조

**메뉴는 로그인 상태에 따라 달라진다**

```
로그인 전 (방문자)          관리자 로그인 후
┌────────────────────┐    ┌────────────────────┐
│ Intent Notes       │    │ Intent Notes       │
│ PORTFOLIO          │    │ ALL POSTS          │
│ STUDY              │    │ PORTFOLIO          │
│                    │    │ RETROSPECTIVE      │
│                    │    │ STUDY              │
│                    │    │ ────────────────── │
│                    │    │ NEW POST           │
│                    │    │ ADMIN              │
│                    │    │   MANAGE MENUS     │
│                    │    │   MANAGE POSTS     │
│ Google 로그인      │    │ 로그인: 관리자     │
│ 관리자 로그인      │    │ @ 알림 · 로그아웃  │
└────────────────────┘    └────────────────────┘
```

**구조 원칙**

- 회고(RETROSPECTIVE)는 **로그인 전에는 메뉴도 글도 없다**
- 메뉴 이름은 사이드바·목록·글쓰기·필터에서 **항상 같다**
- 관리 기능은 사이드바 아래 **ADMIN 묶음**에 모은다

방문자가 Google 로그인하면 이름과 "@ 알림"이 사이드바에 나타난다. 첫 화면은 최신 글 3개를 타일로, 아래에 최근 글 5개를 보여 준다.

## 7. 화면 목록

| 화면 | 대상 | 핵심 요소 | 상태 |

| 첫 화면 | 모두 | 큰 제목, 소개 한 줄, 최신 글 타일, 최근 글 목록(썸네일·조회수) | 체험판 |
| 글 목록 | 모두 | 정렬, 제목 검색, 카테고리별 보기, 썸네일·조회수 | 체험판 |
| 글 상세 | 모두 | 큰 썸네일, 조회수, 공유하기, 본문, 이전·다음 글, 댓글 (관리자는 수정·삭제 막대) | 체험판 |
| Google 로그인 | 방문자 | 계정 선택, 돌아갈 화면 유지 | 모형 |
| @ 알림 | 로그인 사용자 | 나를 부른 댓글 목록, 읽음 처리 | 체험판 |
| 관리자 로그인 | 관리자 | 이메일·비밀번호, 오류 안내 | 모형 |
| 글쓰기·수정 | 관리자 | 제목, 카테고리, 공개 범위, 요약, 썸네일 고르기, 서식 도구, 미리보기 | 체험판 |
| MANAGE POSTS | 관리자 | 필터, 검색, 썸네일·조회수 열, 수정, 공개 전환, 삭제 | 체험판 |
| MANAGE MENUS | 관리자 | 이름·순서·추가·삭제, 나만 보기 메뉴 설정 | 체험판 |

상태: "체험판"은 화면 동작까지 확인됨, "모형"은 화면만 있고 실제 연결 전. 모든 화면은 실제 저장·로그인이 아직 없다.

## 8. 기능 요구사항 (콘텐츠)

**글을 읽고, 쓰고, 공개 범위를 정한다**

| 기능 | 요구사항 | 우선순위 |
|---|---|---|
| 글 목록 | 최신순·오래된순 정렬, 제목 검색, 카테고리별 보기, 썸네일·조회수 표시 | P0 |
| 글 상세 | 제목·요약·날짜·본문, 이전/다음 글, 큰 썸네일 | P0 |
| 글쓰기 | 제목·카테고리·요약·본문, 작성/미리보기 전환 | P0 |
| 공개 범위 | 공개/나만 보기. 나만 보기 메뉴(회고)의 글은 "나만 보기(고정)" | P0 |
| 비공개 글 숨김 | 로그인 전 메뉴·목록·주소 직접 접근 모두 "찾을 수 없어요" | P0 |
| 조회수 | 공개 메뉴 글을 방문자가 열 때마다 +1. 회고·관리자 열람은 제외 | P0 |
| 썸네일 | 모든 글에 표시. 기본 모양 6개 또는 이미지 올리기(1MB 이하, SVG 불가) | P1 |
| 공유하기 | 공개 글만. 링크 복사, X·Facebook·LinkedIn | P1 |
| 서식 도구 | 글꼴·크기·굵기·색, 굵게·기울임·밑줄, 제목·정렬·목록·인용·링크, 붙여넣기 정리 | P1 |
| 후보 기능 | 본문 이미지 넣기, 임시저장·초안 목록 | P2 |

| 글 쓰기·고치기·지우기 | 불가 | 불가 | 가능 |
| 메뉴·공개 범위 관리 | 불가 | 불가 | 가능 |

관리자 권한은 정해 둔 계정 **한 명**만 갖는다. 방문자는 Google 로그인으로 댓글 권한만 갖는다. 이메일·비밀번호 회원가입은 열지 않는다. **이 표는 화면이 아니라 데이터베이스 규칙으로 강제한다.**

## 10. 기능 요구사항 (댓글)

**공개 글 아래의 대화**

- **쓰기:** 로그인한 방문자만, 최대 500자 (제안)
- **날짜·시간:** 모든 댓글에 `2026.11.17 13:47` 형식, 고치면 "(수정됨)"
- **대댓글:** 한 단계로 묶음. 답글에 답글을 달아도 원래 댓글 아래에 모이고, 대상은 @이름으로 표시
- **수정:** 쓴 사람만
- **삭제:** 쓴 사람과 관리자. 답글이 달린 댓글은 "삭제된 댓글입니다"로 남기고 답글은 유지. 한 번 더 확인
- **@ 호출:** @를 입력하면 사람 목록, 부른 이름 강조, 사이드바 "@ 알림"에 개수
- **개인정보:** 이메일은 보이지 않고 이름만 보임 (제안)

**화면 예시**

```
(박) 박지우  2026.11.15 08:47
     평가 지표를 정한 과정이 궁금해요.
     답글 · 수정 · 삭제
     │ (관) 관리자  2026.11.15 12:47
     │      @박지우 다음 글에서 자세히 쓸게요.
```

## 11. 기능 요구사항 (조회수·공유·썸네일)

**읽힌 정도를 보고, 공유하고, 한눈에 구분한다**

| 항목 | 요구사항 |
|---|---|
| **조회수** | 공개 메뉴 글을 방문자가 열 때마다 +1<br>**회고 글은 세지 않고 표시하지 않음**, 관리자 열람도 제외<br>글 목록·첫 화면·글 상세, 글 관리 목록(열)에 표시 |
| **공유하기** | **공개 글에만** 버튼 표시 (나만 보기·회고는 없음)<br>링크 복사, X·Facebook·LinkedIn |
| **썸네일** | 모든 글에 표시: 목록은 작게, 상세는 크게<br>기본 모양 6개 중 선택 또는 이미지 올리기<br>PNG·JPG·WebP·GIF, 1MB 이하, SVG는 받지 않음 |

화면 예시: 공개 글 `[샘플] 프로젝트 제목`(PORTFOLIO, 2026.11.10, 조회 128, [공유하기] 버튼)과 나만 보기 글 `[샘플] 회고 제목`(RETROSPECTIVE · 나만 보기, 2026.11.12, 조회수·공유 없음). 회고 글에도 썸네일은 있지만, 조회수와 공유하기는 없다.

## 12. 기능 요구사항 (관리자 운영)

**메뉴 관리와 글 관리는 따로 둔다**

한 페이지에 모두 담으면 산만해서, 사이드바 ADMIN 아래 두 페이지로 나눴다.

| MANAGE MENUS | MANAGE POSTS |
|---|---|
| 이름 변경: 최대 12자, 중복 불가<br>추가·순서 변경(↑↓)·삭제<br>글이 남은 메뉴는 삭제 불가, 이유 안내<br>삭제는 한 번 더 확인<br>"나만 보기 메뉴" 설정: 켜면 메뉴와 글이 로그인 전에 보이지 않고, 그 안의 글은 나만 보기로 고정<br>기본 메뉴 이름은 영어 (PORTFOLIO, RETROSPECTIVE, STUDY) | 카테고리·공개 범위 필터, 제목 검색<br>글마다 썸네일, 조회수, 수정, 공개 전환, 삭제<br>나만 보기 메뉴의 글은 공개 전환 버튼 없음<br>삭제는 한 번 더 확인, 글을 지우면 그 글의 댓글도 함께 삭제<br>NEW POST는 ADMIN 위 구분선 아래에 둔다<br>글쓰기에서 썸네일 선택(기본 모양 6개 또는 이미지 올리기) |

## 13. 비기능 요구사항

**보안이 가장 먼저, 그다음 품질**

| 구분 | 요구사항 |
|---|---|
| **보안** | 쓰기·비공개 읽기·댓글 권한은 **데이터베이스 규칙**에서 막는다<br>화면에서 버튼을 숨기는 것만으로는 부족<br>글·댓글은 허용한 태그만 남기고 걸러서 표시<br>조회수는 규칙으로 보호, 이미지는 형식·크기 제한(SVG 불가)<br>비밀 값은 `.env`, 저장소에 올리지 않음 |
| **개인정보** | Google 로그인은 이름 등 필요한 만큼만 저장<br>이메일은 다른 방문자에게 보이지 않음<br>공개 저장소에 회고·비공개 내용을 올리지 않음<br>공개 전 내부 자료·실명·수치 직접 확인 |
| **품질** | 모든 화면 휴대폰 너비에서 가로 스크롤 없음<br>버튼·입력칸을 키보드로 사용, 글자 색 대비 확보<br>삭제 같은 되돌리기 어려운 동작은 한 번 더 확인<br>샘플 글과 자리표시자는 공개 전에 삭제 |

## 14. 데이터 모델 (구현됨)

**다섯 가지 데이터**

| 컬렉션 | 들어 있는 것 |
|---|---|
| **settings** | `menus` 공개 메뉴 이름·순서 (누구나 읽기)<br>`private` 나만 보기 메뉴, 전체 순서 (관리자만) |
| **posts** | `title`, `summary`, `date`<br>`category`<br>`visibility` public / private<br>`body` 서식 HTML(format)<br>`thumb` 모양 번호<br>`img` 저장소 이미지 주소 |
| **comments** | `post`, `parent` 대댓글<br>`uid`, `name`, `admin`<br>`text` 500자 이하<br>`mentions` @ 호출<br>`createdAt`, `editedAt`, `gone` |
| **views** | 글 번호별 문서<br>`count` 공개 글만 1씩 |
| **Storage** | `thumbs/` 썸네일 이미지<br>PNG·JPG·WebP·GIF<br>1MB 이하, 올리기는 관리자만 |

**규칙(보안 규칙으로 강제):** 나만 보기 메뉴의 글은 항상 private. 비공개 글에는 댓글·조회수를 만들 수 없다. 글을 지우거나 나만 보기로 바꾸면 그 글의 댓글도 지운다. 이메일은 저장하지 않는다.

## 16. 성공 지표와 출시 기준

**이것이 모두 통과해야 공개한다**

**출시 전 점검 (필수)**

- 비로그인으로 회고 접근 불가 (메뉴·목록·주소)
- 방문자 계정으로 남의 댓글 수정·삭제 불가
- 비공개 글에 댓글 쓰기 불가, 공유하기 버튼 없음
- 회고에 조회수가 없고, 관리자 열람은 세지 않음
- 관리자 아닌 계정의 글 쓰기·지우기 불가
- 샘플 글·자리표시자 제거, 비밀 값이 저장소에 없음
- 휴대폰 너비 점검

**운영 지표 (제안, 목표값은 직접 설정)**

- 발행한 포트폴리오·스터디 글 수
- 글당 조회수와 댓글 수, 답글 비율
- 재방문 방문자 수
- 글 하나를 발행하는 데 걸린 시간
- 비공개 노출 사고 **0건**

지표 수집 방법(분석 도구)은 아직 정하지 않았다.

> **이어지는 문서:** 이 지표를 어떻게 측정할지는 [1차 개선 기획 PRD](PRD-Improve1.md)의 [문제 최종 정의(3.4)](PRD-Improve1.md#34-문제-최종-정의)와 [가설 및 지표(4장)](PRD-Improve1.md#4-가설-및-지표)에서 다룹니다.

## 17. 리스크와 열린 결정

**정해야 할 것, 조심할 것**

| 리스크 | 영향 | 대응 |
|---|---|---|
| 보안 규칙 누락으로 비공개 글 노출 | **매우 큼** | 규칙을 코드로 관리, 계정별로 시험 |
| 글·댓글에 악성 코드 삽입 | **큼** | 허용 태그만 남겨 저장·표시 |
| 공개 저장소에 비공개 내용 유출 | **큼** | `private/` 제외, 자동 커밋은 올리지 않음 |
| 새로고침 반복으로 조회수 조작 | 중간 | 같은 브라우저는 한 번만 집계. 완전 방지는 못 함(열린 결정) |
| 악성 파일이 섞인 썸네일 업로드 | **큼** | 형식·크기 제한, SVG 불가, 저장소 규칙 |
| 스팸·욕설 댓글 | 중간 | 관리자 삭제. 숨기기·신고는 결정 필요 |
| 구글 계정이면 누구나 댓글 가능 | 낮음 | 이름만 저장, 관리자 삭제 |
| 글 저장 형태 이원화 (마크다운/HTML) | 낮음 | 새 글은 HTML로 저장. 옛 마크다운 글도 읽힘 |

**열린 결정**

- 댓글 알림을 이메일로 보낼지
- 부적절한 댓글을 숨기는 기능
- 글을 나만 보기로 바꿀 때 댓글 처리(현재: 함께 삭제)
- 조회수 반복 집계 방지, 인기순 정렬
- 기본 썸네일 자동 생성 여부
- 배포 호스팅과 도메인
- 이메일·비밀번호 로그인 끄기(콘솔)

> **이어지는 문서:** 조회수 반복 집계와 인기 글 판단은 [1차 개선 기획 PRD의 최종 문제(3.4)](PRD-Improve1.md#34-문제-최종-정의)에서 이어집니다.
