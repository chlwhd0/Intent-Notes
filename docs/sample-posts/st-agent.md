## 무엇이 다른가
일반 챗봇은 질문에 **답만** 합니다. 에이전트는 목표를 받으면 **계획하고, 도구를 부르고, 결과를 보고 다음 행동을 정합니다.** 도구는 검색, 파일 읽기, 데이터 조회, 메시지 보내기 같은 것입니다.

## 기본 반복
1. 목표를 이해한다
2. 필요한 도구를 고른다
3. 도구를 실행하고 결과를 읽는다
4. 끝났는지 판단하고, 아니면 2번으로

## 왜 어려운가
- 단계가 늘수록 **한 번의 실수가 뒤로 번집니다.**
- 비용과 시간이 예측하기 어렵습니다.
- 도구가 세상에 영향을 주면(보내기, 지우기) 되돌리기 어렵습니다.

## PM이 정할 경계
- 읽기만 하는 도구와 **쓰기·삭제하는 도구를 구분**하기
- 되돌리기 어려운 동작은 **사람의 확인**을 받기
- 단계 수와 호출 수에 **상한** 두기
- 무엇을 했는지 **기록**하고 사용자에게 보여 주기

## 이 블로그의 원칙
AI가 글을 자동으로 발행·수정·삭제하는 기능은 범위 밖으로 두었습니다. AI는 제안만 하고, 사람이 적용합니다.
