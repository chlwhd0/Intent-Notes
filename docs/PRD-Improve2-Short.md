# PRD: [Intent Notes] 2차 개선, AI로 글쓰기와 공개 전 확인 덜기 (2쪽 요약판)

[원본 v2.2](PRD-Improve2.md)을 2쪽으로 줄인 것입니다. 근거와 세부 기준은 원본을 보세요. 이동: [블로그 PRD](PRD-Blog.md) · [1차 개선](PRD-Improve1.md)

## 1. 기본 정보
**버전** v2.2 요약판 · **작성일** 2026-11-24 · **작성자** 블로그 운영자 · **관련** [원본](PRD-Improve2.md), 시안 `prototypes/ai-features-mockups.html`

## 2. 개요
"AI는 제안만 하고 결정은 사람이 하는" 방식으로 글쓰기와 공개 전 확인의 반복 작업·실수를 줄입니다. 지금은 공개 글 4개 중 **2개의 요약이 비어 있고(50%)**, 푸터에 `[이름]`이 그대로 보입니다. 범위 밖: 챗봇, 번역, 댓글 AI, AI 자동 발행.

## 3. 문제
### 3.1 문제 정의 (사용자 · 문제 · 해결 방안)
| ID | 사용자 | 문제 | 해결 방안 |
|---|---|---|---|
| `AFP1` 작성 부담 | 운영자 | 요약·설명·제목을 매번 손으로 쓰고, 내용이 PDF·회고에 있어 옮기기 번거롭다 | 본문·첨부·회고를 읽고 요약·제목·초안 제안 |
| `AFP2` 공개 전 안전 | 운영자 | 실명·내부 자료·수치·`[이름]`을 눈으로만 확인한다 | 저장 직전 규칙·AI 점검, 해결 전 발행 막기 |
| `AFP3` 독자 이해 | 방문자 | 긴 글의 핵심을 알기 어렵고 이어 볼 글을 직접 찾는다 | 글 위쪽 3줄 요약, 비슷한 글 추천 |
| `AFP4` AI 신뢰·통제 | 운영자·방문자 | 틀린 AI 내용이 걸러지지 않고 비용·원문 전송이 통제되지 않는다 | "AI 초안" 표시, [적용]해야 반영, 월 한도, 처리방침 |

### 3.2 문제 검증
공개 사이트 사실로 확인했습니다(2026-11-24, 관리자 화면은 못 봄). 공개 글 4개 중 **2개는 요약이 비어 있고**, **4개 모두 본문이 50자 이하**이며, 푸터에 `[이름]`이 그대로 보입니다. 방문자·AI 신뢰 쪽은 증거가 약해 만든 뒤 지표로 확인합니다.

## 4. 가설 및 지표
**가설**은 "이 해결 방안을 쓰면 이런 결과가 나올 것이다"라는 아직 검증 전의 예상이고, **지표**로 맞았는지 확인합니다. 글이 4개뿐이라 **운영자 지표를 판단 기준**으로 삼습니다.

| 최종 문제 | 가설 (만약 ~하면, ~할 것이다) | 지표 | 현재 → 목표 |
|---|---|---|---|
| `AFP1` 작성 부담 | AI가 요약을 제안해 주면, 비워 두던 요약이 채워질 것이다 | 요약이 채워진 공개 글 비율 | 50% → 100% |
| `AFP2` 공개 전 안전 | 저장 때 `[이름]` 등을 자동으로 찾아 발행을 막으면, 공개 글에 실수가 남지 않을 것이다 | 공개 글의 위반 건수(월 1회 전수 점검) | 1건 이상 → 0건 |
| `AFP3` 독자 이해 | 3줄 요약과 추천 글을 보여 주면, 방문자가 핵심을 알고 더 읽을 것이다 | 요약 있는 글과 없는 글의 읽기율 비교 | 측정 시작 |
| `AFP4` AI 신뢰·통제 | "AI 초안" 표시, [적용] 승인, 월 한도를 두면, 틀린 내용과 비용이 통제될 것이다 | 방문자가 글을 열 때 AI 호출 횟수, 월 비용 | 0회, 한도 이내 |

## 5. 해결 방안
**컨셉** "AI는 제안, 결정은 사람". 무료 유지(AI 비용만 새로 발생). **KR**: 요약 채움 100%, 공개 화면 자리표시자 0건, 열람당 AI 호출 0회.

| 영역 | AS-IS (지금) | TO-BE (개선 후) |
|---|---|---|
| 요약·설명·제목 | 손으로 쓴다(요약 50% 비어 있음) | 저장 때 AI가 제안, 운영자가 [적용] |
| 공개 전 확인 | 눈으로만 확인(`[이름]` 노출) | 저장 직전 자동 점검, 해결 전 발행 막기 |
| 글 상세 화면 | 본문만 있음 | 위쪽 "AI 요약" 3줄, 아래 "이어서 읽을 글" |
| AI 호출·표시 | 없음 | 저장 때 1회만 호출, 모든 결과에 "AI 초안" 표시, 월 한도 |

## 7. 비기능적 요구사항
AI 키는 서버 보안 설정에만 두고 관리자 확인 후 호출합니다. 방문자 이름·이메일·댓글은 AI로 보내지 않습니다. AI가 실패해도 글쓰기·발행·규칙 점검은 정상이며, 방문자 화면 추가 스크립트는 5KB 이하입니다.

## 8. 디자인 요구사항
기존 시안 2(크림 사이드바, 테라코타 포인트)를 유지하고, AI가 만든 것은 청록 "AI 초안" 표시로 구분합니다.
