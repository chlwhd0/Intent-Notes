# 오늘의 고양이 사진이 화면에 안 보임

## 막힌 일
사이드바의 "오늘의 고양이" 칸에 사진이 나오지 않고 날씨만 보였어요. 서버 응답(`/api/cat`)은 정상이었고, 가짜 응답을 넣은 미리보기에서는 사진이 잘 나왔어요.

## 원인
사진 칸을 `hidden`으로 숨겨 두고 "사진을 다 불러오면 칸을 보이게" 했는데, 사진에 `loading="lazy"`(보일 때 불러오기)가 걸려 있었어요. 브라우저는 숨겨진 칸 안의 사진을 불러오지 않아서 "불러온 뒤 보이게"가 영원히 실행되지 않았어요. 미리보기용 헤드리스 브라우저에서는 이 차이가 드러나지 않았어요.

## 푼 방법
- `loading="lazy"`를 빼고, 칸을 **먼저 보이게 한 뒤** 사진을 불러오게 순서를 바꿨어요(`assets/cat.js`). 불러오기에 실패하면 칸을 다시 숨겨요.
- 실제 사이트를 브라우저 엔진으로 열어 `img.naturalWidth`가 0보다 큰지 확인했어요.

## 다음에 조심할 것
숨겨진 칸 안의 이미지에는 `loading="lazy"`를 쓰지 않아요. 이미지가 실제로 떴는지는 로컬 미리보기가 아니라 실제 사이트에서 확인해요.
