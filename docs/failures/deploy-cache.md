# 배포 후 관리자 화면이 "로그인 확인 중…"에서 멈춤

## 증상
새 디자인을 배포한 직후 관리자로 로그인하면 `admin/posts.html`이 "로그인 확인 중…"만 보이고 사이드바도 비어 있었어요.

## 원인
호스팅이 스크립트와 스타일 파일을 1시간 동안 브라우저에 저장하게 했어요(`cache-control: max-age=3600`). 화면(HTML)은 새것인데 브라우저는 전날 받은 옛 `admin-app.js`를 그대로 써서, 옛 스크립트가 새 화면에 없는 요소를 찾다가 멈췄어요. 가짜 파이어베이스로 같은 코드를 돌렸을 때는 모든 관리자 화면이 정상으로 열려서 코드 문제가 아님을 확인했어요.

## 해결
- 지금 멈춘 화면은 강력 새로고침(Mac 크롬 `Cmd + Shift + R`)으로 풀려요.
- `firebase.json`에 `**/*.@(js|css|json)`도 `Cache-Control: no-cache`로 추가했어요. 매번 새 파일이 있는지 확인하므로 배포하면 바로 적용돼요.

## 다음에 조심할 것
화면(HTML)과 스크립트를 함께 바꿔 배포할 때는 캐시 설정을 먼저 확인해요. 관리자처럼 화면과 스크립트가 짝을 이루는 곳에서 특히 문제가 돼요.
