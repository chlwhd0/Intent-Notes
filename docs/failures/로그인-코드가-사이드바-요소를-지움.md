# 로그인 상태를 그리는 코드가 넣어 둔 칸을 지움

## 막힌 일
사이드바 하단 `#bottom` 안에 넣은 날씨·고양이 칸이 배포 뒤 화면에서 사라졌어요. 또 관리자 화면(글 관리, 메뉴 관리, 새 글, 글 목록, 글 보기)과 관리자 로그인 화면에는 이 칸이 처음부터 없었어요.

## 원인
- 방문자 로그인 상태를 그리는 `assets/site.js`가 `#bottom`의 안쪽을 통째로 다시 썼어요(`innerHTML`). 관리자는 `assets/admin-app.js`가 사이드바 메뉴와 `#bottom`을 다시 그려요. 그 안에 있던 요소가 함께 사라졌어요.
- 관리자 화면 5종(`layout(admin=true)`)과 관리자 로그인은 공개 화면과 틀이 달라서 새 요소를 넣는 자리에서 빠졌어요.
- 로컬 미리보기에서는 파이어베이스를 불러오는 로그인 코드가 돌지 않아서 이 문제가 보이지 않았어요.

## 푼 방법
- 칸을 로그인 코드가 건드리지 않는 별도 영역(`.sidex`)으로 옮겼어요. 컴퓨터는 사이드바, 모바일은 푸터 위 칸을 써요.
- 관리자 화면 5종과 관리자 로그인 화면에도 같은 칸과 스크립트(`cat.js`, `weather.js`)를 넣었어요.
- 화면 종류 14가지 모두에 칸이 들어갔는지 확인했어요.

## 다음에 조심할 것
로그인 코드가 다시 그리는 영역(`#bottom`, 사이드바 `nav`)에는 다른 요소를 넣지 않아요. 새 화면 요소를 넣을 때는 공개 화면 8종, 관리자 화면 5종, 관리자 로그인까지 모든 화면 종류를 확인해요.
